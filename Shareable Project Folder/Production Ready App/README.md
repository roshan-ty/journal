# Complete Windows application

Download and extract the [complete Shareable Project Folder ZIP](https://github.com/roshan-ty/journal/releases/download/v0.3.1/TradersYard-Journal-0.3.1-Shareable-Project.zip).

Open `Shareable Project Folder/Production Ready App/TradersYard Journal.exe` from the extracted folder. Keep all 77 runtime files and their folders together. The full runtime is included in the ZIP; its executable exceeds GitHub's normal Git file-size limit.

Alternatively, [download setup.exe](https://github.com/roshan-ty/journal/releases/download/v0.3.1/setup.exe) to install the same application. The builds are unsigned. Checksums are attached to the release.
