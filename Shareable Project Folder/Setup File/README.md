# Windows installer

[Download setup.exe for TradersYard Journal 0.3.1](https://github.com/roshan-ty/journal/releases/download/v0.3.1/setup.exe).

The installer exceeds GitHub's normal Git file-size limit and is stored as a release asset. It installs the complete application and required runtime. No separate Node.js or Python installation is needed. Setup defaults to Program Files and offers a desktop shortcut and taskbar-pinning instructions. This team build is unsigned.

The same setup.exe is also inside the [complete Shareable Project Folder ZIP](https://github.com/roshan-ty/journal/releases/download/v0.3.1/TradersYard-Journal-0.3.1-Shareable-Project.zip). Checksums are attached to the release.
